# Engineerus Quest

Educational platform for engineering students.

## Features
- AI-powered tutoring
- Gamification system
- Multi-language support (RU/KK/EN)

## Tech Stack
- React + TypeScript
- Node.js + Express
- Vite

## Installation

```bash
npm ci
npm run dev
```

The canonical toolchain is Node.js 24.18.0 with npm 11.16.0. See
[`docs/local-development.md`](docs/local-development.md) for environment,
Supabase CLI, database migration, and validation instructions.
